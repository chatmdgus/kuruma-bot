# 결정 기록

중요한 결정과 이유. 바뀌면 줄을 지우지 말고 아래에 새 결정을 추가한다.

## 2026-10-19
- 작업 중심: claude.ai 대화에서 기획·수정 → GitHub PR → main 머지 시 GitHub Actions가 서버에 자동 배포. 봇이 안 켜지면 자동 롤백.
- kuruma-dev(PC Claude Code + Discord Channels)는 주인 전용. Anthropic 소비자 약관상 Pro 계정을 다른 사람이 쓰게 하면 안 됨.
- 다른 사람이 쓰는 기능은 API(별도 과금)로만 만든다.
- 번역: 평소 GPT(gpt-6-luna), 월 500엔 한도, OpenAI 크레딧 소진/키 오류 시 DeepL로 고정. OpenAI는 $5 선불, 자동충전 꺼짐.
- 번역 품질 목표: GPT vs DeepL 비교 기록으로 DeepL 규칙/단어장을 개선해서, 크레딧이 끝나도 DeepL만으로 만족할 수준.
- 비교 기록은 테스트 채널(비공개)과 서버 파일에만. 이름/ID 넣지 않음.
- 노래 재생 기능은 하지 않음 (유튜브 약관 문제).
- 데이터 파일(.env, data.json, terms.json, names.json, pronouns.json, llm-usage.json, data/)은 저장소에 올리지 않음.
- 모바일에서 한 변경은 staging 브랜치 PR 하나에 모아두고 한 번에 머지/배포.
- 친구용 질문 기능: 호출어 "야 쿠루마". kuruma-dev(주인 Pro 계정)는 약관상 다른 사람이 못 쓰고 PC 꺼지면 죽으니 안 씀 → 이미 충전한 OpenAI API(GPT)로. 번역과 크레딧·월 한도 공유, 질문 기능은 월 100엔·1인 하루 20회.
- 질문 기능 호출어 변경: 주인 이름이 쿠루마라서 한국어 "야 쿠루마봇", 일본어 카타카나 "クルマ"(+ボット/ねえ 가능). 일본어는 뒤에 띄어쓰기·、가 있어야 반응 ("クルマで" 같은 차 뜻 오인 방지).
- 봇 이름 정리: 번역봇(kuruma bot) → "차봇", kuruma-dev(진짜 Claude, 주인 전용) → "쿠루마봇". 질문 기능은 차봇 안에 있으니 호출어도 "야 차봇" / "チャボット、"로. 질문 메시지는 번역·다른 기능 다 건너뛰고 대답은 한/일 둘 다.
- 차봇 질문 기능(ask.js)은 끔: GPT는 번역에만 씀. 질문은 쿠루마봇(진짜 Claude, 주인 전용)으로.
- 쿠루마봇이 서버에서 직접 고치면 바로 커밋·푸시해야 함 (커밋 안 된 수정이 있으면 자동 배포가 멈춤). 2026-10-19 서버 수정분은 PR #7(server-sync)로 반영.

## 2026-10-21
- 오버레이 중계(overlay-relay.js): 게이트웨이 연결은 차봇 하나만, 오버레이 앱은 차봇에 WebSocket으로 붙음. OVERLAY_PORT 있을 때만 켜짐(opt-in), 127.0.0.1에만 열고 외부 노출은 나중에 Cloudflare Tunnel.
- 오버레이 인증은 마일스톤1 동안 OVERLAY_TOKENS(`유저ID:비밀값`) 임시 방식. Discord OAuth2로 바꿀 예정. 메시지 내용은 로그·저장 안 함.
- 오버레이에서 쓴 글은 채널별 "kuruma-overlay" 웹훅으로 (이름·프사는 보낸 사람 것, 멘션 알림 없음). 삭제 규칙 채널(BOOTH_FREE/BOOTH_ONLY/CLIP_ONLY)은 보기만 되고 보내기 막음.
